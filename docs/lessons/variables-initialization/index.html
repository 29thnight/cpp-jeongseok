NAME. INITIALIZE.
USE.>_TYPES / VALUES / SCOPE

앞 수업에서는 소스 코드를 수정하고 빌드한 뒤 실행 결과를 확인했습니다. 이번에는 프로그램이 기억할 값에 이름을 붙입니다. 게임에 남아 있는 횟수, 캐릭터의 속도, 시작 준비 여부를 각각 저장하고, 필요한 곳에서 이름으로 꺼내 쓰는 연습입니다.

예제는 C++20 콘솔 프로젝트에서 하나씩 실행합니다. 같은 프로젝트에 main 함수를 여러 개 넣지 않으며, 짧은 설명용 코드 조각과 완전한 실행 예제를 구분합니다.

이 수업을 마치면

  1. 정수, 소수 부분이 있는 수, 참과 거짓, 기본 문자에 알맞은 타입을 골라 변수 네 개를 초기화하고 출력할 수 있습니다.
  2. 변수의 초기화와 대입을 구분하고, 초기화 누락과 좁히기 변환이 있는 코드를 찾아 수정할 수 있습니다.
  3. const 변수와 중첩 블록을 포함한 코드에서 변경할 수 있는 값과 각 출력 위치에서 사용되는 변수를 설명할 수 있습니다.

1 이름과 타입과 값을 함께 읽습니다

프로그램에서 값을 담아 두고 이름으로 사용하는 대상을 변수라고 부릅니다. 이번 수업의 변수는 하나의 기본형 값을 저장합니다. 다음 한 줄을 살펴보겠습니다.

int remainingAttempts{3};

int는 저장할 값의 종류를 나타내는 타입입니다. remainingAttempts는 우리가 정한 변수 이름이고, 3은 처음 저장할 값입니다. 중괄호 안의 값으로 변수를 처음 준비하는 일을 초기화라고 합니다. 세미콜론은 이 선언을 마칩니다.

이 문장은 “남은 횟수를 나타내는 int 변수를 만들고 처음 값을 3으로 정한다”라고 읽습니다. 이름은 대상을 찾는 데 사용하고, 타입은 표현할 값의 종류를 정하며, 값은 현재 기억한 내용입니다.

변수를 이해할 때는 이름표가 붙은 보관함을 떠올려도 좋습니다. 이름표에는 용도를 쓰고, 보관함의 종류에 맞는 값을 넣습니다. 다만 이 비유는 이름·타입·값의 역할을 구분하기 위한 것입니다. 실제 메모리 배치나 컴퓨터 내부 구조를 그대로 보여 주지는 않습니다.

변수 값을 출력하려면 std::cout << remainingAttempts << std::endl;처럼 이름을 씁니다. 이름을 큰따옴표로 감싸면 변수의 값 대신 그 글자를 그대로 출력합니다.

2 값의 용도에 맞는 타입을 고릅니다

int는 정수에 사용합니다

int는 소수 부분이 없는 정수를 표현하는 타입입니다. 남은 횟수 3, 현재 점수 120, 기준점 아래의 위치 -2처럼 정수로 다룰 값에 사용합니다. 음수도 표현할 수 있습니다.

int가 표현할 수 있는 범위에는 한계가 있습니다. C++20은 최소 16비트 너비를 요구하지만 정확히 32비트라고 고정하지 않습니다. [참고 1]

double은 소수 부분이 있는 수에 사용합니다

double은 부동소수점 타입입니다. 이동 속도 2.5나 온도 18.75처럼 소수 부분이 필요한 수를 표현할 때 사용할 수 있습니다. 이번 예제에서는 double movementSpeed{2.5};처럼 작성합니다.

double도 표현 범위와 정밀도에 한계가 있습니다. 구체적인 표현 방식은 구현에 따라 달라지며, 모든 실수를 정확하게 표현하지는 않습니다. 이번에는 간단한 값을 저장하고 출력하며 계산 오차는 뒤에서 다루겠습니다. [참고 1]

bool은 참과 거짓을 표현합니다

bool에는 true와 false라는 두 값이 있습니다. 시작 준비가 되었는지, 소리가 켜져 있는지처럼 두 상태로 표현할 내용에 잘 맞습니다. 예를 들어 bool isReady{true};는 준비 여부를 참으로 초기화합니다.

true와 false는 C++에서 정해진 표기이므로 작은따옴표나 큰따옴표로 감싸지 않습니다. 이 수업의 기본 출력 설정에서는 bool 값이 1과 0으로 보입니다. true는 1, false는 0으로 출력된다는 점을 예상 결과에서 확인합니다. [참고 2]

char는 기본 문자 예제에 사용합니다

char는 'A', '7', '?'처럼 기본 문자를 다루는 예제에 사용할 수 있는 타입입니다. char rank{'B'};에서 'B'는 작은따옴표로 감싼 문자 리터럴입니다. 문자 리터럴은 코드에 직접 적은 문자 값을 뜻합니다.

숫자 7과 문자 '7'은 구별해야 합니다. 전자는 정수 값이고 후자는 숫자 모양을 가진 문자입니다. 또한 'B'와 "B"도 같은 표기가 아닙니다. 이번에는 char를 초기화할 때 작은따옴표를 사용한다는 점을 익힙니다.

char 하나에 한글 한 글자나 이모지 하나가 항상 들어간다고 생각해서는 안 됩니다. 문자의 표현에는 인코딩이 관련됩니다. 이번 char 예제는 영문자와 기본 기호로 제한합니다. [참고 3]

3 예제 01 네 종류의 값을 저장하고 출력합니다

다음 프로그램은 작은 게임의 상태를 네 개의 변수로 기록합니다. 실행 전에 각 줄의 출력이 무엇일지 먼저 적어 봅니다.

#include <iostream>

int main()
{
    int remainingAttempts{3};
    double movementSpeed{2.5};
    bool isReady{true};
    char rank{'B'};

    std::cout << remainingAttempts << std::endl;
    std::cout << movementSpeed << std::endl;
    std::cout << isReady << std::endl;
    std::cout << rank << std::endl;

    return 0;
}

예상 출력

3
2.5
1
B

선언에서 고른 타입과 저장한 값을 한 쌍씩 연결해 보겠습니다. remainingAttempts는 횟수이므로 int, movementSpeed는 소수 부분이 있으므로 double입니다. isReady는 준비 여부이므로 bool이고, rank는 한 개의 기본 문자로 표시하므로 char입니다.

isReady의 초기값만 false로 바꾼 뒤 저장하고 다시 빌드해 실행합니다. 세 번째 줄만 0으로 바뀝니다. 한 번에 한 값을 바꾸면 소스와 결과의 관계를 관찰하기 쉽습니다.

4 초기화와 대입을 구분합니다

초기화는 변수를 만들면서 처음 값을 정하는 일입니다. 대입은 이미 있는 변수에 값을 저장하는 일입니다. 다음 코드 조각에서 두 작업을 찾아보겠습니다.

int remainingAttempts{3};
remainingAttempts = 2;

첫 번째 줄은 int 변수를 정의하면서 3으로 초기화합니다. 두 번째 줄은 기존 변수에 2를 대입합니다. 두 번째 줄 앞에 int를 다시 쓰지 않습니다. 이 코드가 순서대로 실행된 뒤 remainingAttempts의 현재 값은 2입니다.

C++에서 이 형태의 =는 대입에 사용합니다. 오른쪽에서 얻은 값을 왼쪽 변수에 저장한다고 읽습니다. 수학의 등호처럼 두 식이 같다고 주장하는 문장이 아닙니다. “remainingAttempts에 2를 저장합니다”라고 소리 내어 읽으면 방향을 기억하기 쉽습니다.

초기화에도 =를 사용하는 표기가 있습니다. 예를 들어 int score = 10;은 score를 처음 정의하는 선언이므로 초기화입니다. 그다음의 score = 20;은 이미 있는 변수에 대한 대입입니다. =가 있다는 이유만으로 모두 대입이라고 분류하지 않습니다. [참고 4]

이번 수업에서는 처음 값을 정할 때 int score{10};처럼 중괄호를 사용하겠습니다. 처음 생성되는 시점과 나중에 값을 바꾸는 시점이 눈에 잘 구분되고, 뒤에서 설명할 좁히기 변환도 확인하기 좋습니다.

다른 변수의 현재 값으로 초기화할 수도 있습니다. 이때 기본형 변수는 그 시점의 값을 받아 저장합니다. 뒤의 const 예제에서 이 모습을 확인하겠습니다.

5 빈 중괄호로 초기값을 정합니다

초기값을 생략하고 싶은 때에도 변수가 어떤 값으로 시작하는지 분명하게 해 두는 편이 좋습니다. 이번에 배우는 네 기본형에 빈 중괄호 {}를 사용하면 다음과 같이 초기화됩니다. [참고 4, 5]

  • int count{};는 0으로 초기화합니다.
  • double distance{};는 0.0으로 초기화합니다.
  • bool isReady{};는 false로 초기화합니다.
  • char mark{};는 값이 0인 널 문자 '\0'으로 초기화합니다.

널 문자 '\0'은 숫자 모양의 문자 '0'이나 공백 문자 ' '와 다릅니다. 널 문자는 화면에 눈에 보이는 글자처럼 표시되지 않을 수 있으므로, 이 수업에서는 mark에 'A'를 대입한 뒤 출력하겠습니다.

6 예제 02 처음 값과 바뀐 값을 비교합니다

이번 예제에서는 먼저 빈 중괄호로 초기화한 값을 확인하고, 같은 변수들에 새 값을 대입합니다. 소수 타입인 double의 값 0.0도 기본 출력에서는 0으로 보일 수 있습니다.

#include <iostream>

int main()
{
    int remainingAttempts{};
    double movementSpeed{};
    bool isReady{};
    char rank{};

    std::cout << remainingAttempts << std::endl;
    std::cout << movementSpeed << std::endl;
    std::cout << isReady << std::endl;

    remainingAttempts = 3;
    movementSpeed = 2.5;
    isReady = true;
    rank = 'A';

    std::cout << remainingAttempts << std::endl;
    std::cout << movementSpeed << std::endl;
    std::cout << isReady << std::endl;
    std::cout << rank << std::endl;

    return 0;
}

예상 출력

0
0
0
3
2.5
1
A

처음 세 줄은 대입하기 전의 값을 보여 줍니다. 그다음 네 줄은 새 값을 대입한 뒤의 결과입니다. rank도 처음부터 '\0'으로 초기화되어 있지만, 첫 출력 묶음에서는 출력하지 않았습니다.

이 예제를 int remainingAttempts;처럼 중괄호까지 지운 코드와 혼동하지 않습니다. 함수 안의 일반 지역 변수 int remainingAttempts;에는 사용할 수 있는 초기값이 주어지지 않습니다. 여기에 먼저 값을 저장하지 않고 출력하거나 계산에 사용하면 C++20에서는 정의되지 않은 동작이 발생합니다. [참고 6]

정의되지 않은 동작은 “무작위 숫자 하나가 나온다”라는 뜻으로 한정할 수 없습니다. 언어가 그 실행 결과를 보장하지 않는다는 뜻입니다. 우연히 0이 출력되었더라도 그 코드는 올바른 프로그램이 되지 않습니다. 실행해서 나온 숫자로 안전 여부를 판단하지 않습니다.

선언 자체가 곧바로 문제인 것은 아닙니다. int score; 다음에 score = 10;을 실행하고 나서 값을 읽을 수 있습니다. 다만 처음 선언할 때 값을 정하는 습관이 좋습니다. 전역 변수나 static 지역 변수의 초기화는 별도의 규칙을 따릅니다.

7 중괄호가 확인해 주는 좁히기 변환

변수에 넣으려는 값의 타입과 변수의 타입이 다르면 변환이 필요할 수 있습니다. 중괄호 초기화는 C++에서 좁히기 변환으로 정한 변환을 허용하지 않습니다. 다음은 의도적으로 오류를 살펴보는 코드 조각입니다. 정상 실행 예제에 그대로 추가하지 않습니다. [참고 5]

int remainingAttempts{3.7};

3.7은 부동소수점 값이고, remainingAttempts는 정수 타입입니다. 부동소수점에서 정수로 바꾸는 변환은 여기서 허용되지 않습니다. 값의 목적을 다시 확인하여, 소수 부분이 필요하면 double로 선언하고 정수 횟수라면 정수 초기값을 사용합니다.

double movementSpeed{3.7};
int remainingAttempts{3};

int remainingAttempts{3.0};도 좁히기 변환에 해당합니다. 소수 부분이 0이라는 이유로 예외가 되지 않습니다. 반면 double movementSpeed{3};은 허용됩니다. 중괄호가 서로 다른 타입의 모든 변환을 금지하는 것은 아닙니다.

오류를 만났을 때는 중괄호를 바꾸어 진단만 없애려 하지 않습니다. 먼저 저장하려는 내용이 정수인지, 소수 부분을 유지해야 하는 수인지 판단합니다.

중괄호 초기화의 검사가 일반 대입문에 자동으로 적용되는 것은 아닙니다. 나중에 대입할 값도 변수의 용도와 타입에 맞는지 살펴야 합니다.

8 const로 변경하지 않을 값을 표현합니다

한 번 정한 뒤 바뀌면 안 되는 기본형 값에는 const를 붙일 수 있습니다. 예를 들어 const int maximumAttempts{3};은 최대 횟수를 3으로 초기화합니다. 이후 maximumAttempts = 5;처럼 값을 바꾸는 문장은 허용되지 않습니다. [참고 7]

이번 수업의 const 기본형 변수는 정의할 때 초기값을 주어야 합니다. const int maximumAttempts;처럼 초기화하지 않은 채 두고 나중에 값을 대입하는 방식으로 사용하지 않습니다. 초기화와 이후 변경은 서로 다른 단계입니다.

const라고 해서 초기값이 반드시 코드에 적힌 숫자여야 하는 것은 아닙니다. 다른 변수의 현재 값으로 초기화할 수 있고, 실행 중에 얻은 값으로 초기화하는 것도 가능합니다. 초기화가 끝난 뒤 그 const 객체의 값을 변경할 수 없다는 점이 핵심입니다.

예제 03 현재 값을 복사해 고정합니다

#include <iostream>

int main()
{
    int currentLevel{3};
    const int startingLevel{currentLevel};

    std::cout << currentLevel << std::endl;
    std::cout << startingLevel << std::endl;

    currentLevel = 5;

    std::cout << currentLevel << std::endl;
    std::cout << startingLevel << std::endl;

    return 0;
}

예상 출력

3
3
5
3

startingLevel은 초기화할 때 currentLevel의 값 3을 받아 시작합니다. currentLevel은 나중에 5로 바뀌지만 startingLevel은 3을 유지합니다. 저장한 값이 두 변수 사이에서 실시간으로 연결되는 구조가 아니라는 점을 다시 확인할 수 있습니다.

상수식으로 초기화해야 한다는 요구는 constexpr로 나타낼 수 있으며, constexpr 변수의 객체는 const가 됩니다. const 변수도 조건에 따라 상수식에서 사용할 수 있으므로 “const는 항상 실행 시간”이라고 단정하지 않습니다. 여기서는 const가 초기화 이후 변경을 제한한다는 점까지 익힙니다. [참고 8]

9 이름에 값의 역할을 담습니다

변수 이름은 프로그램을 읽을 사람을 위한 단서입니다. int a{3};보다 int remainingAttempts{3};이 어떤 값을 담는지 설명하기 쉽습니다. 모든 이름을 길게 만들 필요는 없지만, 주변 문맥과 함께 읽었을 때 용도가 드러나야 합니다.

이번 수업에서는 영문자로 시작하고 영문자·숫자·밑줄을 조합한 이름을 사용합니다. 숫자로 시작하지 않고, 공백을 넣지 않으며, int와 bool 같은 C++ 키워드를 이름으로 쓰지 않습니다. 대소문자는 구별되므로 score와 Score는 다른 이름입니다. [참고 9]

remainingAttempts처럼 단어 첫 글자의 대소문자를 이용하거나 remaining_attempts처럼 밑줄로 단어를 구분할 수 있습니다. 어느 한 방식이 문법상 필수인 것은 아니며, 사용하는 코드의 규칙에 맞춰 일관되게 작성합니다.

구현에 예약된 이름과 겹치지 않도록, 처음에는 밑줄로 시작하거나 이중 밑줄이 들어간 이름을 피합니다. C++ 식별자가 영문자만 허용하는 것은 아니며, 영문 중심의 이름은 이번 수업의 규칙입니다.

10 블록 안에서 이름을 사용합니다

여러 문장을 중괄호로 묶은 영역을 블록이라고 합니다. main의 본문 안에도 더 작은 블록을 만들 수 있습니다. 블록 안에 선언한 지역 변수 이름은 선언 지점부터 그 블록 끝까지 사용할 수 있습니다. 이를 블록 범위라고 합니다. [참고 10]

바깥 블록에서 선언한 이름은 안쪽 블록에서도 사용할 수 있습니다. 다만 안쪽에 같은 이름의 변수를 새로 선언하면 그 지점부터 안쪽 이름이 바깥 이름을 가립니다. 두 변수가 하나로 합쳐지거나 바깥 변수가 삭제되는 것은 아닙니다.

예제 04 같은 이름이 가리키는 대상을 확인합니다

#include <iostream>

int main()
{
    int score{5};
    std::cout << score << std::endl;

    {
        int score{20};
        std::cout << score << std::endl;

        score = 21;
        std::cout << score << std::endl;
    }

    std::cout << score << std::endl;
    return 0;
}

예상 출력

5
20
21
5

첫 번째 출력에서 score는 바깥 변수를 가리키므로 5입니다. 안쪽 블록에서 int score{20};을 만나면 별개의 지역 변수가 만들어집니다. 그 뒤 안쪽의 두 출력문과 score = 21;은 안쪽 변수를 사용합니다.

안쪽 블록의 끝에 도달하면 안쪽 이름의 범위가 끝납니다. 마지막 출력에서는 바깥 score를 다시 사용합니다. 바깥 변수에는 새 값을 대입한 적이 없으므로 5가 출력됩니다.

안쪽 이름이 바깥 이름을 가리는 현상을 이름 가리기, 또는 섀도잉이라고 부릅니다. 관찰을 위해 일부러 같은 이름을 썼으며, 평소에는 이름을 구별하면 읽기 쉽습니다. 도구가 이름 가리기 경고를 보여 줄 수도 있습니다.

중괄호의 두 역할을 구별합니다

int score{5};의 중괄호는 초기값을 적는 부분입니다. 예제 04에서 여러 문장을 둘러싼 중괄호는 블록을 만듭니다. 같은 기호라도 위치와 문맥에 따라 역할이 달라집니다. 중괄호를 볼 때 그 안에 초기값이 들어 있는지, 실행할 문장들이 들어 있는지 살펴봅니다.

11 스스로 확인하는 다섯 문제

답을 보기 전에 변수 이름 옆에 현재 값을 적으며 풀어 봅니다. 오류를 포함한 문제는 정상 프로그램처럼 실행하지 않고, 문제가 되는 이유를 먼저 설명합니다.

문제 1 타입을 선택합니다

다음 네 항목을 각각 한 줄의 선언으로 작성합니다. 변수 이름은 제시한 이름을 사용하고 중괄호로 초기화합니다.

  1. 남은 횟수 remainingAttempts의 값은 4입니다.
  2. 이동 속도 movementSpeed의 값은 1.5입니다.
  3. 준비 여부 isReady의 값은 false입니다.
  4. 등급 rank의 값은 문자 C입니다.

문제 2 초기화와 대입을 구분합니다

다음 코드 조각의 각 줄에서 어떤 일이 일어나는지 설명합니다. 마지막에 first와 second에 들어 있는 값을 각각 적습니다.

int first{8};
int second{first};
first = 12;
second = 4;

문제 3 문제를 찾아 수정합니다

다음 세 코드 조각은 서로 별개입니다. 그대로 사용해도 되는지 판단하고, 문제가 있다면 이유와 수정 방법을 씁니다. 모두 main 안에 있는 일반 지역 변수라고 가정합니다.

가

int count;
std::cout << count << std::endl;

나

int speed{2.5};

다

bool isReady{};
std::cout << isReady << std::endl;

문제 4 const의 효과를 설명합니다

다음 코드 조각의 마지막 줄에서 두 변수의 값은 각각 무엇입니까? 아래에 saved = 9;를 추가하면 허용되는지도 설명합니다.

int current{6};
const int saved{current};
current = 9;

문제 5 이름의 범위를 추적합니다

다음 코드 조각의 출력 세 줄을 예상합니다. main의 본문 안에 있다고 가정합니다. 안쪽 블록 끝의 중괄호 다음에 std::cout << bonus << std::endl;을 추가하면 사용할 수 있는지도 설명합니다.

int score{10};
{
    int score{30};
    int bonus{2};
    std::cout << score << std::endl;
    std::cout << bonus << std::endl;
}
std::cout << score << std::endl;

12 정답과 해설

문제 1 정답

int remainingAttempts{4};
double movementSpeed{1.5};
bool isReady{false};
char rank{'C'};

횟수에는 int, 소수 부분이 필요한 속도에는 double, 두 상태를 표현하는 준비 여부에는 bool, 기본 문자로 나타낸 등급에는 char를 사용합니다. false에는 따옴표를 붙이지 않고, 문자 C에는 작은따옴표를 사용합니다. 네 선언 모두 처음 값을 명시합니다.

문제 2 정답

첫 번째 줄은 first를 8로 초기화합니다. 두 번째 줄은 그 시점의 first 값을 사용하여 second를 8로 초기화합니다. 세 번째 줄은 first에 12를 대입하고, 네 번째 줄은 second에 4를 대입합니다. 마지막 값은 first가 12, second가 4입니다.

문제 3 정답

가에서는 count에 값을 저장하기 전에 그 값을 읽어 출력하려 합니다. C++20에서 이러한 미초기화 int 값의 사용은 정의되지 않은 동작입니다. 0부터 시작하려는 의도라면 int count{};로 고칩니다. 특정 개수부터 시작하려면 int count{3};처럼 의미 있는 초기값을 정합니다.

나에서는 부동소수점 값 2.5를 int로 중괄호 초기화하려 하므로 좁히기 변환 진단이 발생합니다. 속도의 소수 부분을 유지하려면 double speed{2.5};로 고칩니다. 원래 정수만 필요한 항목이었다면 뜻에 맞는 정수 초기값을 선택해야 합니다.

다는 올바릅니다. 빈 중괄호로 isReady를 false로 초기화했으며, 이 수업의 기본 출력 설정에서는 0이 출력됩니다. int count;처럼 초기값을 준비하지 않은 선언과 빈 중괄호를 사용한 선언을 구별하는 문제입니다.

문제 4 정답

current는 9이고 saved는 6입니다. saved는 초기화 시점의 값을 받아 고정하며, current의 이후 변경을 따라가지 않습니다. saved = 9;를 추가하면 const 변수에 대입하려 하므로 허용되지 않습니다.

문제 5 정답

출력은 차례로 30, 2, 10입니다. 안쪽 블록에서는 안쪽 score가 바깥 score를 가립니다. 안쪽 블록을 벗어난 마지막 출력에서는 바깥 score를 사용합니다. 바깥 score에는 새 값을 대입하지 않았으므로 10이 유지됩니다.

bonus는 안쪽 블록에 선언되어 있으므로 그 블록 밖에서 이름을 사용할 수 없습니다. 블록 밖에 bonus 출력문을 추가하면 선언을 찾을 수 없어 컴파일 오류가 발생합니다. 필요하다면 실제로 사용할 범위 안에서 선언 위치를 다시 설계해야 합니다.

13 다음 코드를 작성하기 전 확인합니다

새 변수를 만들 때는 이름이 용도를 설명하는지, 타입이 값에 맞는지, 처음 사용할 때 값이 준비되어 있는지 확인합니다. 중첩 블록에서는 현재 이름이 가리키는 선언도 살펴봅니다.

이번 수업의 중심 습관은 간단합니다. 변수를 만들 때 용도에 맞는 타입과 첫 값을 함께 정합니다. 이후 값을 바꿀 때는 대입한다는 사실을 의식하고, 바뀌지 않아야 하는 기본형 값에는 const를 사용합니다.
