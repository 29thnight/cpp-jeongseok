이 책에서 배울 것

C++은 값과 객체가 언제 만들어지고, 누가 사용하며, 언제 사라지는지를 직접 이해할 수 있는 언어입니다. 문법을 외우는 데서 멈추지 않고, 코드가 동작하는 이유를 설명하는 것이 이 강좌의 목표입니다.

처음에는 작은 프로그램을 완성합니다. 그다음 타입과 함수, 객체의 수명과 소유권을 배우고, 표준 라이브러리와 제네릭 프로그래밍으로 문제를 표현합니다. 마지막에는 큰 코드베이스의 설계를 읽을 수 있는 기반을 쌓습니다.

이 페이지는 강좌의 방향과 읽는 방법을 소개하는 초안입니다. 아래 학습 목차의 본 강좌들은 아직 작성 중입니다.

제1판과 C++20

제1판은 교재의 판본이고, C++20은 예제의 기준 언어 표준입니다. 두 번호는 서로 다른 의미를 가집니다. 교재의 설명과 구성이 바뀌어도 언어 표준은 그대로일 수 있습니다.

예제는 특별한 표시가 없다면 C++20을 기준으로 합니다. 더 새로운 기능을 다루게 되면 필요한 표준과 도구 지원을 별도로 표시합니다. 오래된 코드의 표현은 그것을 읽는 데 필요한 맥락에서 소개합니다.

첫 번째 코드 읽기

아직 모든 문법을 이해할 필요는 없습니다. 프로그램 안에서 데이터가 만들어지고, 사용되고, 정리되는 순서를 먼저 살펴봅시다.

#include <iostream>
#include <string>
#include <vector>

int main()
{
    const std::vector<std::string> topics{
        "values", "lifetime", "ownership"
    };

    for (const auto& topic : topics) {
        std::cout << topic << '\n';
    }
}

이 프로그램은 세 개의 단어를 한 줄씩 출력합니다. topics는 문자열을 담는 컨테이너이고, 반복문은 각 문자열을 차례로 읽습니다.

  • const는 이 객체를 통해 내용을 변경하지 않겠다는 뜻입니다
  • const auto&는 각 원소를 복사하지 않고 읽기 위한 참조를 만듭니다
  • topics의 수명이 끝나면 컨테이너와 그 원소가 소멸하며, 소유한 자원이 정리됩니다

당장 직접 메모리를 할당하거나 해제할 필요는 없습니다. 먼저 표준 라이브러리의 값 타입을 활용하고, 이후에 그 뒤의 수명과 소유권 규칙을 배웁니다.

읽고, 바꾸고, 설명하기

한 절을 읽을 때 다음 세 단계를 반복해 보세요.

  1. 예제를 읽고 실행 결과를 예상합니다
  2. 한 가지를 바꾼 뒤 예상과 실제 결과를 비교합니다
  3. 결과가 달라진 이유를 자신의 말로 설명합니다

위 예제에서는 문자열 하나를 추가해 보세요. 다음으로 const auto&를 auto로 바꾸면 무엇이 달라질지 생각해 보세요. 출력은 같을 수 있지만, 반복할 때 문자열을 복사한다는 차이가 있습니다.
