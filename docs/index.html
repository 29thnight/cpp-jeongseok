ABOUT THE BOOK

문법 너머의
이해를 향해서

무엇을 쓸 수 있는지보다, 왜 그렇게 쓰는지를 배웁니다. 현대적인 표준 라이브러리와 안전한 기본 관용구를 먼저 익히고, 그 선택을 뒷받침하는 원리를 연결합니다.

01 / 원리

수명과 소유권

객체가 언제 생기고 사라지는지, 자원을 누가 책임지는지 이해합니다.

02 / 표현

명확한 코드

타입과 인터페이스로 의도를 드러내는 방법을 배웁니다.

03 / 확장

큰 코드의 구조

실제 프로젝트와 엔진 코드도 읽을 수 있는 기반을 쌓습니다.
