# 02-2 문자열 예제 실행 안내

학습 기준: Visual Studio / MSVC, C++20. 모든 예제는 각각 `main()`이 있는 독립 프로그램입니다. 한 프로젝트에 여러 예제를 동시에 추가하지 마세요. 예제 하나씩 실행합니다.

## Visual Studio에서 실행

1. C++ 콘솔 앱 프로젝트를 만듭니다
2. 기존 소스 대신 실행할 예제 하나를 추가합니다
3. 프로젝트 속성 → C/C++ → 언어 → C++ 언어 표준을 `/std:c++20`으로 설정합니다
4. C/C++ → 명령줄 → 추가 옵션에 `/utf-8`을 설정합니다
5. 빌드하고 실행합니다

Developer Command Prompt for Visual Studio에서는 다음 명령을 사용할 수 있습니다. 아래는 실행 안내이며, 이 패키지를 만들 때 MSVC로 실제 실행한 기록은 아닙니다.

```bat
cl /std:c++20 /EHsc /W4 /utf-8 01_length_empty.cpp /Fe:01_length_empty.exe
01_length_empty.exe
```

다른 예제는 파일명을 바꿔 각각 빌드합니다. `06_getline`은 한 줄을 입력하고 Enter를 누르세요. `07_number_then_line`은 숫자를 입력하고 Enter를 누른 뒤, 이름 한 줄을 입력하세요.

## 예제 순서

- `01_length_empty.cpp`: 길이, 빈 문자열, 공백 한 칸의 차이
- `02_concatenation.cpp`: 문자열과 문자 이어 붙이기
- `03_find_npos.cpp`: 찾은 위치, 0번 위치, 못 찾았을 때의 `npos`
- `04_find_boundaries.cpp`: 시작 위치와 빈 검색어의 경계 사례
- `05_char_and_string.cpp`: 작은따옴표 문자와 큰따옴표 문자열
- `06_getline.cpp`: 공백을 포함한 한 줄, 빈 줄, 입력 실패
- `07_number_then_line.cpp`: `>>` 뒤 남은 줄을 `ignore`로 비우고 다음 줄 읽기
- `08_bytes_and_text.cpp`: `sizeof(char)`와 UTF-8 문자열 길이의 차이

`auto`는 오른쪽 값의 자료형을 컴파일러가 정하도록 합니다. 여기서는 `find`의 위치 자료형을 그대로 받습니다. `npos`는 못 찾았다는 표시이며 정상적인 위치처럼 사용하지 않습니다. `contains`는 C++23 기능이므로 C++20 예제에서는 쓰지 않습니다.

`07`의 `ignore`는 숫자 뒤에서 줄 끝까지 모두 버립니다. 따라서 이름을 숫자와 같은 줄에 쓰면 이름도 버려집니다. 빈 이름 줄은 성공적으로 읽은 빈 문자열입니다. 숫자 입력 실패나 이름 줄이 없는 경우에는 별도 메시지로 종료합니다. 숫자 뒤의 모든 문자가 올바른 숫자 형식인지 검사하는 예제는 아닙니다.

`08`은 UTF-8 바이트를 `\xEA\xB0\x80`으로 직접 지정합니다. 출력은 ASCII뿐이므로 콘솔의 한글 출력 설정에 의존하지 않습니다. 이 예제의 특정 한글 음절은 유니코드 코드 포인트 1개이고 UTF-8 바이트 3개입니다. 일반적으로 화면상 글자 수와 코드 포인트 수가 항상 일치하는 것은 아닙니다. `std::string::length()`는 저장된 `char` 단위 수를 반환합니다. `sizeof(char)`는 항상 1이며, 문자열의 글자 수를 알려 주지 않습니다.

## 검증 범위

Visual Studio/MSVC에서 직접 실행한 기록은 포함하지 않습니다. 본문의 예상 출력과 비교하며 각 예제를 직접 실행하세요. 이 묶음에는 소스 8개와 실행 안내만 들어 있으며 실행 파일이나 빌드 산출물은 없습니다.
